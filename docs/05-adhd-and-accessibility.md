# ADHD & accessibility

ADHD brains thrive on **novelty, quick feedback and clear next steps**, and struggle with walls of text, hidden progress and long unbroken tasks. Maths adds working memory load (holding steps in your head), so MathsMzansi is designed to reduce it.

## Built in

- **Step mode** – lessons show one chunk at a time with a big "Got it – next" button and ← → keys.
- **Worked examples one step at a time** – no wall of algebra; each line comes with "Why?".
- **One problem at a time** in practice blocks, with progress dots.
- **Instant feedback** everywhere, with specific hints instead of a bare ✗.
- **Focus sprints** – a 5/10/15/25-minute timer with movement-break suggestions.
- **Consistent colour meaning** – Algebra is violet, Geometry orange, Trigonometry teal; red only ever means a mistake; pink is a memory hook; amber is an exam tip; blue is a Mzansi moment.
- **Visible progress** – progress bars per lesson, topic and strand; XP and streaks.

## Preferences (top-right button)

| Setting | What it does |
|---|---|
| Theme | Light, dark or high contrast |
| Font | Inter, Atkinson Hyperlegible or OpenDyslexic |
| Text size & line spacing | Bigger text, more space between lines |
| Calm mode | Switches off all decorative animation (also follows the OS "reduce motion" setting) |
| Reading ruler | A highlight band that follows the pointer |
| Word anchors | Bolds the first half of each word to guide the eye (never inside formulas) |
| Read-aloud speed | For the read-aloud buttons – which also read maths ("x squared", "3 over 4", "root 5") |
| Focus mode | Hides the navigation so only the lesson remains |

## Accessibility basics

Keyboard navigation everywhere, visible focus rings, skip link, ARIA labels on interactive SVGs, minimum 32 px touch targets, no information conveyed by colour alone, and maths rendered with KaTeX (which includes MathML for screen readers).
